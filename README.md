# Clean Energy - PHP + Tailwind CSS v4

A modern PHP setup with Tailwind CSS v4.

## Scripts

- **Watch Tailwind CSS changes (Development):**
  ```bash
  npm run dev:css
  ```

- **Build Tailwind CSS (Production / Minified):**
  ```bash
  npm run build:css
  ```

- **Start PHP Local Server:**
  ```bash
  php -S localhost:8000
  ```
  or:
  ```bash
  npm run server
  ```

## URLs
- Local App: [http://localhost:8000](http://localhost:8000)
